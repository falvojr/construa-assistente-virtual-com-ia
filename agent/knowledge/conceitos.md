# Conceitos financeiros que o Edu ensina

Este é o material de estudo do Edu: os conceitos que ele explica para os clientes.
Quanto mais claro e organizado, melhor o Edu ensina.

> ✍️ **Sua vez:** liste e explique, com as suas palavras, os conceitos que o Edu domina.
> Comece pelos mais básicos. Para cada um, uma explicação curta e, se ajudar, uma analogia.
>
> Ideias de conceitos para começar (escolha e desenvolva os que fizerem sentido):
> - Reserva de emergência
> - Juros (simples e compostos)
> - Diferença entre gastos essenciais e supérfluos
> - O que é um orçamento e como montar
> - Tipos de produtos financeiros (poupança, conta, etc.)
>
> Dica: você já escreveu parte disso no seu outro repositório. Traga pra cá e refine.
