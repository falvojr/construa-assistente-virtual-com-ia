# Dados do cliente (mockados)

Esta pasta guarda os dados de exemplo que o Edu usa para personalizar as explicações.

> ✍️ **Sua vez:** copie para cá os seus dados mockados (você já os tem no outro repositório).
> Sugestão de arquivos:
> - `perfil_investidor.json`: perfil e objetivos do cliente
> - `transacoes.csv`: histórico de gastos e receitas
> - `produtos_financeiros.json`: produtos disponíveis para ensino
>
> Depois de adicioná-los, documente cada um em `agent/knowledge/cliente.md` para que o Edu
> saiba interpretá-los.

> ℹ️ Você pode apagar este `README.md` quando colocar os dados reais aqui.
